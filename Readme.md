# Advanced Library Management System

A Django REST Framework-based library management system demonstrating clean architecture and object-oriented design principles.

## Quick Start

```bash
cd library_hackathon
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_data --create-users
python manage.py runserver
```

See [library_hackathon/README.md](library_hackathon/README.md) for complete documentation.
